# 项目说明 · 自托管「任务 + 财务」管理系统

> **用途**：本文档帮你向其他使用者介绍这个项目在做什么、能做什么，并收集他们自己的需求和建议。
> 看不懂技术细节没关系，重点看「我们能用到什么」和「还缺什么」两节，把你的想法填在文末即可。

---

## 一、这项目是要解决什么？

我们想在**自己的群晖 NAS**上搭一套系统，把日常工作的**「任务管理」和「记账/财务」**合在一起管，不依赖任何第三方云服务（数据自己掌握）。

核心痛点：
- 任务分散、到期容易忘；
- 一个项目花了多少钱、还剩多少预算，没人说得清；
- 贷款/定期扣款这类固定支出，希望自动记账、不用每月手动记；
- 想在电脑和手机上都能用，还能在手机上收到提醒。

---

## 二、我们能用到什么（已实现设计）

### 1. 任务管理（Vikunja）
| 能力 | 说明 |
|---|---|
| 三层结构 | 类别 → 项目 → 任务，层级清晰 |
| 时间管理 | 每件事可设**开始时间 / 结束时间 / 截止日期** |
| 里程碑 | 用「里程碑」标记关键节点 |
| 提醒 | **临期提醒 + 到期提醒**，通过邮件发送；提前几天可每个任务单独设 |
| 交付物 | 记录这件事要交付什么（文件/文档） |
| 任务详情 | 描述、负责人、优先级等 |
| 所需资源 | 记录这事需要什么资源（人/物/设备），用标签记 |
| 所需资金 | 记录这事预算多少，用标签记（如 `fund:5000`） |
| 移动端 | 手机浏览器加到主屏当 App 用；还能通过 **CalDAV** 把任务同步进手机系统提醒 |

### 2. 财务管理（ezBookkeeping）
| 能力 | 说明 |
|---|---|
| 记账 | 支出 / 收入 / 结余一目了然 |
| 统计分析 | 收支趋势、分类占比、净资产曲线等图表 |
| 资金池 | 只分「**现金**」「**存款**」两大类 |
| 多用户共享 | 一个共享资金池，谁记的账都带 `by:用户名` 标记，可追溯 |
| 移动端 | 有官方手机 App（安卓/iOS），登录即用 |
| 定期扣款 | **贷款还款**这类每月固定支出，设为「周期交易」后**自动记账**，不用手动 |

### 3. 两套系统自动联动（n8n 自动化）
- 在任务里填了预算 → 财务侧自动登一笔「计划支出」；
- 任务标记完成 → 财务侧自动记一笔「实际支出」；
- 财务侧贷款自动扣款 → 自动把对应的任务勾掉，不重复记。
- 三套程序都跑在同一台 NAS 内网里，互相通信不经过外网，更快也更安全。

### 4. 访问与部署
- 跑在群晖 Docker 里，外网用 **HTTPS（加密访问）** + 自有域名访问；
- 电脑/手机浏览器自适应，手机也能顺畅操作；
- 数据每天自动备份，只保留最近 3 份，存在 NAS 共享文件夹里。

## 三、整体架构（给技术同学看）

```
   电脑 / 手机  ──HTTPS──▶  Nginx 反代  ──▶  tasks.你的域名  → Vikunja（任务）
                                      ├──▶  fin.你的域名   → ezBookkeeping（财务）
                                      └──▶  flow.你的域名  → n8n（自动化后台）

   Vikunja ──Webhook──▶ n8n ──API──▶ ezBookkeeping   （任务→财务 自动同步）
   ezBookkeeping ──轮询──▶ n8n ──API──▶ Vikunja       （财务→任务 自动同步）
   全部走 NAS 内网，不经公网
```

技术栈：Vikunja + ezBookkeeping + n8n + Nginx Proxy Manager + ddns-go，均为 Docker 容器，数据库用轻量的 SQLite。

---

## 四、已经定下来的事（决策）

- 任务系统用 **Vikunja**，财务系统用 **ezBookkeeping**（不要 Firefly III，因其无手机原生 App）；
- 自动化用 **n8n** 双向同步；
- 任务里的「所需资源 / 所需资金 / 交付物」用**标签**记录（零代码，先跑通）；
- 用户：任务系统 3 个账号（其中 1 人兼管理员），财务用 1 个共享账号；
- 不开启两步验证（2FA）；
- 定期扣款（如房贷）由财务系统**每月自动过账**，任务系统只做跟踪、不弹提醒；
- 备份写 NAS 共享文件夹，仅留 3 份。

## 五、还缺什么 / 想听你的建议（重点）

以下是我们**还没完全定、或想听听你意见**的地方，欢迎补充：

1. **统计看板**：现在财务统计靠 ezBookkeeping 自带报表。你希望有更直观的「项目预算 vs 实际」对比图吗？还是自带报表够用？
2. **预算体验**：目前「预算」是用一笔「计划支出」近似的，没有独立的预算上限/超额预警。你需要「超预算自动提醒」吗？
3. **提醒方式**：现在是「邮件 + 手机系统提醒（CalDAV）」。还需要微信/钉钉/飞书推送吗？
4. **权限**：3 个人共用一个财务资金池够不够？要不要更细的「谁能看哪笔账」？
5. **任务字段**：除了上面列的，你还希望任务能记什么？（比如：优先级规则、附件大小、关联文档链接……）
6. **其他**：任何你觉得「要是用起来，我还会想要……」的功能。
