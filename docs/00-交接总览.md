# 项目交接总览 · 任务 + 财务自托管系统

> **给下一台机器 WorkBuddy 的入口说明**
> 本包是「群晖 Docker 上的任务管理器 + 财务管理系统 + 自动化桥接」项目的完整交接资料。
> **请先读本文档，再按需读 `01-需求与决策记录.md`、`02-审查问题与待办.md`、`03-实施部署手册.md`。**

## 一、项目一句话定位
在群晖 DS1618+ 上用 Docker 自托管一套 **任务管理（Vikunja）+ 财务管理（ezBookkeeping）+ 自动化桥接（n8n）** 的系统：支持类别/项目/任务、起止时间、里程碑、临期/到期邮件提醒、交付物、任务详情、所需资源、所需资金；财务侧有支出/收入/结余与统计分析；三系统通过 n8n 自动联动，互相通信只在群晖内网；外网经 NPM + Let's Encrypt HTTPS + Namecheap DDNS 访问，移动端自适应 + CalDAV 同步手机提醒。

## 四、关键决策速查（详情见 `01-需求与决策记录.md`）
| 维度 | 决策 |
|---|---|
| 任务系统 | Vikunja（类别=Namespace，项目=Project，任务=Task） |
| 财务系统 | ezBookkeeping（不要 Firefly III，因其无原生 App 且统计够用即可） |
| 桥接 | n8n，B 方案（自动双向同步），走 Docker 内网 |
| 数据库 | 两系统均优先 SQLite |
| 自定义字段 | Path A 标签编码（`fund:`/`res:`/`deliv:`/`milestone`），零代码 |
| 多用户 | Vikunja 3 用户（1 兼管理员）；ezBookkeeping 1 个共享资金池账号 + `by:用户名` 标记 |
| 资金池账户 | 只建「现金」「存款」两类 |
| 证书 | Let's Encrypt 自动续期（免手动替换）；自签仅离线备选 |
| 外网 | 真公网 IP + 动态 IP → Namecheap DDNS + NPM HTTPS |
| 子域名 | tasks / fin / flow（主域名不动） |
| 邮件 | QQ 邮箱 SMTP（smtp.qq.com:465） |
| 内部通信 | 三系统只走 Docker 内网，不经公网 |
| 备份 | 原生全量（vikunja dump ZIP + ezB db）+ 高压缩 + 写群晖 `/share/backup` + 仅留 3 份 |
| 定期扣款 | ezB 周期交易每月自动过账（权威来源）；Vikunja「定期扣款」项目仅跟踪；贷款不提醒 |
| 提醒 | 每任务手工设提前量；手机系统提醒由 CalDAV 覆盖；Vikunja 邮件作兜底 |
| 2FA | 不开 |

## 七、最该警惕的 3 个坑
1. **CalDAV 闹钟可靠性**：方案假设"手机系统提醒由 CalDAV 覆盖"，但 Vikunja CalDAV 未必导出 VALARM，手机可能只显示日历事件而不弹闹钟。这是当前最大的功能不确定性，需实机验证；若不行，可靠提醒仍是 Vikunja 邮件。
2. **n8n JSON 未实机校验**：4 个工作流是设计阶段产物，标签解析（`fund:`）、金额×100、Webhook 路径、节点 `typeVersion` 都可能在实机报错，需调试。
3. **`/share/backup` 路径**：DSM 共享文件夹实际挂载通常是 `/volume1/share/backup`，`/share/backup` 可能不存在，需按真实路径改 `backup.sh` 的 `SMB_DIR`。
